# Engineering Portfolio Website

A responsive single-page portfolio for an Electronics and Communication Engineering student, covering:
- Digital design / RTL (asynchronous FIFO and UART)
- Embedded systems (predictive maintenance and automated billing)
- Analog IC design (5T OTA and CMOS bandgap reference)

## Files
- `index.html` — page content and project cards
- `styles.css` — responsive dark theme and layouts
- `script.js` — mobile navigation, project filters, and active section navigation
- `assets/` — place your resume, actual simulation screenshots, diagrams, and project evidence here

## Run locally
Open `index.html` in a browser. No build step is required.

## Before publishing
1. Confirm the displayed name and contact details.
2. Add your real LinkedIn and GitHub profile URLs.
3. Confirm current CGPA, OTA technology node, BGR temperature range, and project descriptions against your actual work.
4. Add actual simulation screenshots and results. Placeholder labels are intentional; no unprovided measurements have been invented.
5. Only claim features and verification results you can demonstrate.
6. Add your resume PDF to `assets/` and link it from the hero or contact section if desired.
7. Test on mobile and desktop.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `engineering-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets/` folder to the repository root.
3. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

Google Fonts are loaded from Google Fonts; system sans-serif fallbacks are included.
