# Prateek Bolagond — ECE Portfolio

## Files
- `index.html` — page content and sections
- `styles.css` — dark theme, layout, photo hero, responsive design
- `script.js` — resume dropdown, mobile navigation, project filters

## Upload to GitHub Pages
Upload `index.html`, `styles.css`, and `script.js` to the same folder in your repository.
Keep your existing resume PDFs in that folder:
- `embeded system resume.pdf`
- `analog resume.pdf`
- `digital resume.pdf`

The hero photo is loaded from an external Unsplash URL, so an internet connection is required for that image.

## Contact links
Check your email, GitHub profile URL, and LinkedIn profile URL in `index.html` before publishing.
